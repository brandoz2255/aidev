# Harvis sandbox

This directory is **yours across turns** in Harvis. Write files here. They persist.

## Interpreters (run what you write)

| Runtime | Command |
|---|---|
| Python 3 | `python3 script.py` |
| Node.js | `node script.js` |
| Bash | `bash script.sh` |
| Syntax check | `bash harvis-check.sh` |

You **may** use Bash to run those commands. Do not reach the public web from here.

## Notes

Keep working notes in `notes.md`. That file survives the next message. Do not claim you cannot write — you can.

## How to answer

Use Markdown: headings, short paragraphs, and fenced code blocks with a language tag. When you write a script, save it here **and** show it in a fenced block so the user sees it typed. After edits, run `bash harvis-check.sh` and report what it said.

## Do not

- Reveal API keys, tokens, hostnames, or private paths
- Tell the user to open files on their own machine — Harvis previews them
- Browse the public web from this sandbox
